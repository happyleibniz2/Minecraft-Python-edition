## Preparing the assets

1. Obtain the model from your own copy of Genshin Impact.
2. Convert the FBX to OBJ in Blender.
3. Export textures as PNG.
4. Place them in `assets/`.
5. Install the mod folder into `mods/paimon/`.

Required filenames:
- `paimon_body.png`
- `paimon_face.png`
- `paimon_hair.png`
- `paimon_cloak.png`
- `paimon.obj`
